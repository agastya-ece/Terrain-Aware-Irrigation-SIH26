# ESP32

ESP32 firmware and experiments developed for the SIH 2026 smart irrigation system.

## Development Environment

* **Microcontroller:** ESP32 DevKit V1
* **Framework:** Arduino
* **IDE:** PlatformIO
* **Programming Language:** C++

## Experiments

### 1. Basic LED Blink

Initial ESP32 test to verify board setup, GPIO control, and firmware uploading.

### 2. Serial Communication

Testing communication between the ESP32 and the serial monitor.

### 3. DHT11 Sensor

Reading temperature and humidity data from a DHT11 sensor.
